EllysPearls

The meaning of the question 1000 is that each point has a color, and points of the same color are required to be placed together. Ask how many times the current order of these points needs to be changed.

The question explanation says that if 15 usually appears, consider bitmask dp. And this dp is actually very classic. It is [0,1] that indicates whether the current color has been added to the set and whether it has been considered. Then the color at the last position is recorded and it is over.
