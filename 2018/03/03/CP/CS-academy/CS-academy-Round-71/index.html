D Russian Dolls

Each of the N balls has a corresponding size, and small balls can be nested inside large balls. A ball can only nest one small ball, but it can be nested recursively. Now you can make $1$ balls of size $X$ into $2$ balls of size $X-1$. It is required that when there is no way to nest in the end, the size of each ball is the same. Ask how many operations are required at least.

The final situation achieved is that the largest number of balls is the largest.

Start enumerating from the current largest number of balls to see how many operations are needed. Then change the largest ball into two second largest balls, and then enumerate the number of operations required for the current number.

Complexity $O(log^2N)$.

E Losing Nim

Output the number of solutions whose sum is $N$ divided into $K$ piles, and the XOR is $0$. Each pile is at least $1$, $K$ from $1$ to $N$. $1<N<500$

I wrote a dp of $O(N^4)$. . . Then I saw that all the operations were repeated, but I didn’t know how to optimize it to $O(N^3)$.

ans[i][j][k] represents the number of solutions to the i-th heap, the sum is j, the XOR is k, and then the last heap is enumerated.

TLE.

Later, I asked others and found that dp[i][k] can represent the number of options in which the sum of the first i digits is k and the XOR is 0. The inside is transferred through the combination number.
