B Box and Ball

The meaning of the question is that n boxes are given, the first box has a red ball in it, and the rest have white balls. Now there are m operations, each time a ball is randomly drawn from the x-th box and placed in the y-th box. Ask how many boxes are likely to contain red balls in the end.

Anyone who has an affair will be counted. Please note that there is no ball in the box.

C Knot Puzzle

The meaning of the question is that there are n pieces of rope, and each piece of rope has a length. Now these n pieces of rope are connected together, and Snuke wants to take it apart. The requirement is to choose a length of at least L before it can be broken into two pieces. Ask if this piece of rope can be broken into n pieces and give a strategy.

At the beginning of this question, I was greedy and started to split it from both ends, and found that it was wrong. For example, in this case:

4 6
3 3 1 4

It is better to select the maximum value of the adjacent sum, and if it satisfies >=L, this segment will be the last segment.

D Stamp Rally

The meaning of the question is to give an undirected connected graph, and then ask x, y, z q times, and find out after which edge the number of nodes connected by x and y is, and the number is greater than or equal to z.

The problem seemed very scary when I was doing it. In fact, for each query, it is to see which time after adding an edge, the sum of the number of the two union sets is greater than z. Then for q queries, we use the idea of ​​​​dividing the whole, save the mid in the vector, and then run the whole together. Keep narrowing it down each time.

F Leftmost Ball

The meaning of the question is that there are balls of n colors, ranging from 1 to n, and there are k balls of each color. Now arrange these balls in a row, and dye the leftmost ball of each color into color 0. Ask how many possible final ball arrangements there are.

This dp is also awesome. . . .

It is very wonderful to convert these n*k balls into a graph. The gray ball represents the color 0, and then ask how many topological sortings there can be in this graph. (ORZ….)

How many kinds are there next? . . And use dp to solve (ORZ….)

For each situation dp[i][j], there are two options: 1. Take a gray ball dp[i-1][j]. 2. Take an orange ball and put it first in the current position, then the position of the remaining k-2 balls is arbitrary, that is, C(i+j*(k-1)-1, k-2)*dp[i][j-1].

Finally multiply the result by n!
